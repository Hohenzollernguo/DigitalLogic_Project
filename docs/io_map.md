# EGO1 IO 表与上板核对

器件为 `xc7a35tcsg324-1`；P17 提供 100 MHz，XDC 时钟周期为 10 ns。引脚来源为项目附带 `EGo1(1).xdc`，电平和器件信息依据 EGO1 手册 §2、4、6。这里只约束实际使用的 51 个端口位，不导入原文件中 UART/VGA/SRAM 等无关外设及无效分隔行。

## 输入

| 顶层端口 | FPGA 引脚 | 暂定用途 |
|---|---|---|
| sys_clk_in | P17 | 系统时钟 |
| reset_pin | P15 | S6 复位，极性待测，参数控制 |
| btn_pin[0] | R11 | S0 确认 |
| btn_pin[1] | R17 | S1 展示切换 |
| btn_pin[2] | R15 | S2 撤回 |
| btn_pin[3] | V1 | S3 演示推进 |
| tile_sw[3:0] | P5、P4、P3、P2 | 编号 MSB 到 LSB，物理左右方向待核实 |
| mode_sw | R2 | 0 游戏、1 演示 |

S4 保留，不声明也不约束。手册对应 P5/P4/P3/P2 为 SW7/SW6/SW5/SW4，R2 为 SW3；与示例 XDC 中 `sw_pin` 下标不同。不能只按 SW 下标推断左右位置。五个通用按键按下高有效；S6 需单独核实。

## LED 输出

| 顶层端口 | 从左到右的引脚 | 逻辑来源 |
|---|---|---|
| led_pin[0]～[7] | F6 G4 G3 J4 H4 J3 J2 K2 | info_leds[7]～[0]，提示编号 1～8 或有效/无效统计 |
| led_pin[8]～[11] | K1 H6 H5 J5 | tile9_leds[3]～[0] |
| led_pin[12] | K6 | 高级外设，基础方案灭 |
| led_pin[13] | L1 | 游戏模式 |
| led_pin[14] | M1 | 演示模式 |
| led_pin[15] | K3 | 错误闪烁、通关长亮 |

LED 高有效；上述左右顺序由官方项目说明指定。顶层已显式反转逻辑向量至示例约束索引。

## 数码管输出

| 端口 | 下标从 0 到 7 的引脚 |
|---|---|
| seg_cs_pin | G2 C2 C1 H1 G1 F1 E1 G6 |
| seg_data_0_pin | B4 A4 A3 B1 A1 B3 B2 D5 |
| seg_data_1_pin | D4 E3 D3 F4 F3 E2 D2 H2 |

两组段总线的 bit0～7 为 a、b、c、d、e、f、g、dp；位选和段选均高有效。`symbols` 是从左到右的逻辑字符，不能据此认定 `seg_cs_pin[0]` 就是最左侧；扫描驱动需依据实机结果映射。

- [ ] 依次拨动编号开关，确认物理最左对应 bit3；必要时只调整 XDC 对应关系。
- [ ] 逐个点亮 16 个 LED，对照上表及项目官方图。
- [ ] 数码管逐位显示编号/测试字符，确认左右组、位序和段序。
- [ ] 检查普通按键消抖、长按只触发一次、同时输入优先级。
- [ ] 实现后检查所有 IO 与时钟约束、CDC、DRC、时序；不通过降低 DRC 严重性绕过问题。

当前 XDC 不设置输入/输出 delay 或随意增加 false path。待同步器实现后由 C 按实际电路检查 CDC 和时序例外；有完整 PACKAGE_PIN 不等于时序验证完成。
