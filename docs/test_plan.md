# 测试计划

基础脚本只验证骨架，可运行项目不等于功能已完成。以下验收均待补充与执行。

## 现有 testbench 的边界

| 入口 | 当前检查 | 开发下一步 |
|---|---|---|
| tb_game_core | 复位/空闲状态 | 使用 send_command 任务加入真实核心功能用例；ready 低会超时 |
| tb_display | 注入棋盘状态，output_blank 时全灭 | 棋盘/提示/E/十进制/闪烁/扫描 |
| tb_control | 输入、路由、演示连线，复位/空闲无请求 | 用可控 ready 验证背压与序列，输入抖动/长按 |
| tb_top | 复位异步置位/两拍释放、核心复位接线、LED 位序、全灭覆盖 | 游戏与演示端到端流程 |

测试驱动在下降沿改变同步输入，检查在上升沿更新后进行。tb_top 使用 force 注入显示层逻辑输出验证连线；这只用于测试，不会进入综合。所有测试设有超时保护，失败应使用 `$fatal`，成功打印与 testbench 同名 PASS 标记。

## A：核心功能

- [ ] INIT/PLAY/WON/STATS/错误/演示各阶段复位，历史不残留（F01）。
- [ ] 正常逐格输入；0 在前八格/第九格；重复和 9～15；第九格非法后纠正（F02～F03）。
- [ ] 空位在全部九个位置，覆盖邻接与非邻接；索引 2↔3、5↔6 不可跨行（F07～F09）。
- [ ] 0、9～15 移动不越界；有效/无效分别计数，另一项不变。
- [ ] 123456708 移动 8 → 123456780；WON 保持棋盘，再确认 STATS；初始目标棋盘（F12～F13）。
- [ ] 有效/无效移动后撤回；无历史；撤回后再移动；展示切换不覆盖历史（F14）。
- [ ] LOAD_DEMO 清零错误、计数、历史，并正确判断阶段。
- [ ] cmd_ready=0 时无状态变化；同一命令只接收一次；保留 opcode 忽略。

- [ ] 棋盘 123456708 → mask=00001011；123456780 → mask=00000101。
- [ ] 未填和棋子 0 都空白但不混淆；当前错误格 E、第九格错误 1111（F04～F06）。
- [ ] 普通游戏复位后统计、奇数次提示、偶数次统计；演示按最终口径（F11）。
- [ ] 有效/无效 09→10、15；十进制位于最左两位/最右两位，中间空白；超范围待确认（F13）。
- [ ] 错误闪烁、WON/STATS 长亮、模式灯、全灭覆盖全部输出（F17）。
- [ ] 两组扫描、段码、位码、0/E/空白和切位无串位；实机确认方向（F18）。
